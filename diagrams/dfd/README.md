# Data Flow Diagram (DFD Level 1) Specification

## 1. Overview
The Data Flow Diagram represents the logical movement of data from user inputs, through validation, weighted risk estimation, SDLC scoring, dynamic synthesis, and persistence in SQLite.

## 2. Draw.io Rendering Instructions
1. Open [https://app.diagrams.net](https://app.diagrams.net).
2. Choose **File > Open From > Device**.
3. Select `dfd_diagram.xml` located in this directory.
