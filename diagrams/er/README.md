# Entity-Relationship (ER) Diagram Specification

## 1. Overview
The ER Diagram defines the relational data schema in SQLite for the `projects` and `assessments` tables, enforcing foreign key integrity and cascade deletion.

## 2. Draw.io Rendering Instructions
1. Open [https://app.diagrams.net](https://app.diagrams.net).
2. Choose **File > Open From > Device**.
3. Select `er_diagram.xml` located in this directory.
