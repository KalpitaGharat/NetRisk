# Activity Diagram Specification

## 1. Overview
The Activity Diagram details the algorithmic flow of execution across swimlanes: User/Presentation, Backend FastAPI services, and Database persistence.

## 2. Draw.io Rendering Instructions
1. Open [https://app.diagrams.net](https://app.diagrams.net).
2. Choose **File > Open From > Device**.
3. Select `activity_diagram.xml` located in this directory.
